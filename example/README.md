# Example Data

This directory contains a sample data set for Cadence with fictional project contexts and topics.

## How to use

1. Launch Cadence
2. Open Settings (⌘,)
3. Set the **Data directory** to this `example/` folder
4. Restart the app

## What's included

**Contexts (4):**
- Website Redesign (Development group)
- API Project (Development group)
- Team Offsite (Organization group)
- Product Launch (Organization group)

**Topics (8):**
- Various statuses: new, follow-up, waiting, done
- Various priorities: high, medium, low
- Various directions: discuss, deliver, waiting
- Topics with and without due dates
- One recurring topic (monthly)
- Several topics with update notes

All data is completely fictional and contains no personal or company-specific information.
